# 岁己旧录播题材搜索与切片手册

这份手册记录跨年份搜索岁己旧录播、制作老岁片或普通小岁片时已经验证过的流程。目标是先快速找到“可切的事实窗口”，再用统一压制方法得到可上传成片。

## 1. 先定位录播，不先看画面

1. 先搜 D 盘当前录播：`D:\files\videos\DDTV录播\25788785_岁己SUI`。近期场次通常还在这里，先按年份/月和日期目录缩小范围。
2. 如果目标日期较老、D 盘没有对应日期目录，或已经确认录播被归档，再搜 E 盘机械盘：`E:\EFiles\Evideo\DDTV录播-E\25788785_岁己SUI`。E 盘是归档源，不是切片输出目录。
3. D/E 两处都先查文字侧车文件：`.srt`、`.xml`、`.asr_meta.json` 及同目录的摘要/文本；用 `rg -l` 或 `rg --count-matches` 先得到候选文件和日期，命中后再找对应视频。
4. 优先搜索 `.srt`、`.xml`、`.asr_meta.json`，视频只在文字命中后抽查。
5. 关键词要准备同义词和 ASR 误识别：
   - 硬件：`CPU`、`12400F`、`3050`、`显卡`、`内存`、`任务管理器`、`性能`、`插槽`。
   - 事件：`拔智齿`、`牙洞`、`咕涌`、`含一口水`、`弹幕`。
   - 情绪：`不准`、`生气`、`不愿意`、`不要换`、`涨价`、`哈哈`。
6. 两个本地根目录都找不到文字证据时，再扩大日期范围；本地证据穷尽后才考虑下载 B 站回放。不把识图作为第一轮筛选手段。

推荐的最小检索骨架：

```powershell
$roots = @(
  'D:\files\videos\DDTV录播\25788785_岁己SUI'
  'E:\EFiles\Evideo\DDTV录播-E\25788785_岁己SUI'
)
foreach ($root in $roots) {
  if (Test-Path -LiteralPath $root) {
    rg -l -S --glob '*.srt' --glob '*.xml' --glob '*.asr_meta.json' '关键词' $root
  }
}
```

先按 D -> E 的顺序处理输出，避免 E 盘归档和 D 盘当前录播出现重复命中时把同一场当成两场；需要时用文件名、日期目录和媒体时长去重。

## 2. XML/SRT 联合定位

- SRT 用于主播语音的时间轴和上下文，XML 用于观众弹幕的时间、重复次数和事件触发。
- 先用 `rg -n -C` 找命中行，再向前后扩展 30-120 秒，找到“起因-反应-收束”的完整窗口。
- 弹幕复述常常比 ASR 更准确，例如 `12400F`、`3050 是显卡` 这类硬件纠正可作为交叉证据，但不能把弹幕内容写成主播说过的话。
- 旧 SRT 质量差时，不能直接相信句子边界；用更宽的粗剪窗口，重新 ASR 后再确定字幕边界。

## 3. 粗剪、ASR 与字幕校准

1. 先用宽窗口粗剪，保留前后铺垫和自然停顿，优先速度。
2. 使用 `topic_clipper.cutClipMedia()` 的两段式 `copy` 模式，让程序探测真实媒体起点，再校准字幕相对时间。
3. 不要为了字幕对齐把粗剪改成精剪；精剪只用于最终边界微调，不能成为默认流程。
4. 旧录播人工 SRT 有明显错字时，只修正关键实体词和标题相关句子，避免大面积手改造成新的时间轴偏移。
5. 输出必须使用通用大字幕压制参数（字体大小、边距、双阶段烧录），不要为单条片另设小字幕参数。

## 4. 内容取舍与命名

- 跨多年旧题材优先保留能独立成立的“起因-反驳/误会-笑点”窗口；长段闲聊可以拆成多个精华窗口。
- 电脑配置、任务管理器截图、弹幕纠正等事实型片段，标题应写清可验证事实。
- 普通近期直播片使用 `【小岁】` 前缀；跨年份回顾、旧录播搜索出的片段可使用“老岁片”前缀，但必须由任务明确指定。
- 标题、简介、封面文字三者分工：标题负责钩子，简介只陈述片中内容，封面文字短而可读。不要把内部选材理由写进公开简介。

## 5. 上传前检查

- 检查 MP4、SRT、JSON、封面和投稿文案是否齐全。
- 检查成片实际时长、字幕首尾时间和关键句是否同步。
- 新切片优先导入结构化 metadata JSON；历史任务仍可先写 REVIEW，再用 `clip_upload_registry.py import-review` 获得短 ID。只入队用户确认过的 ID。
- 上传 worker 是单实例，优先 `enqueue`，不要直接调用 `batch_upload.py`。

## 6. 快速命令

普通自动切片结束后查看残余候选：

```powershell
node src/scripts/own_stream_residual_audit.js --srt "录播.srt" --xml "录播.xml" --plan "own_stream_fun_clips/PLAN.json"
```

手工候选队列的完整用法见 `docs/manual-clip-queue.md`。
