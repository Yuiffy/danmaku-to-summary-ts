# 切片能力与外部技术评估

本页是供鹿饼对外比较技术的公开资料，描述项目具备的实现与约束。
它不证明某台机器已启用全部能力，也不代替具体素材的质量、耗时或费用实测。
变更切片能力时应同步本节；凭据、内部路径、用户原文和单次实验结果不写入本页。

## 公开能力摘要

选材：使用录播字幕、弹幕和话题证据生成候选，保留原话位置与上下文；搜索与候选不是最终剪辑或人物归属的证明。
制作：支持普通、重点前置和精切三种模式；重点前置串接重点、品牌片头与正文，精切包含故事删减、画面强调与独立质量检查；失败保留普通版并记录。
字幕：有原音核对、字幕修订、统一烧录和时间轴映射，人物、关键词与边界依赖源证据，抽样画面不能代替逐字校对。
视觉：已维护带时间映射的抽帧、图版与连续帧取证；外部自适应场景拼图仍属独立评估方案，不能称已接入自动切片。
画质：维护独立的超分、去噪等增强流程；它改善画质，不直接解决选材和叙事，强去噪可能损失纹理。
审核：保留首尾、改词、片头接缝、封面和完整成片检查，候选审核与投稿授权分开。
评估：外部技术应分别比较选材召回、叙事连贯、边界准确、字幕正确、耗时与真实模型用量；固定同一素材和模型，不能用演示效果或图片张数替代收益实测。
