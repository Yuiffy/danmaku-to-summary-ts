# 快乐小岁游戏长精切

在仓库根目录执行。先读 [sui-clip-queue](../sui-clip-queue/SKILL.md)，沿用其素材检索、
GPU 调度、成片审核与上传注册表规则。本 skill 补充系列长精切的编辑判断；完整游戏存档
仍走 `docs/stream-game-clips.md`，普通小切片仍走原队列。

## 找到上一集的终点

从上一集的制作清单、原始来源列表与最终时间轴恢复进度，记录 `sourceId`、录播内秒数、
最后发生的事和待接的目标。成片时间不能当录播时间。先核对实际文件和来源身份，
排除上一集正文已用的区间；开头预告复用本集正文属于有意重复，另行标识。
续集的推进点以最后保留内容为准，不能把整场直播标为已做完。

## 选材与节奏

用户提供参考截图时，先确认原 B 站视频，再研究实际的预告长度、转场和笑点铺垫；
截图只能证明画面样式，不能证明节奏。参考其表达方法，内容和系列身份仍来自岁己素材。

- 允许多场直播组成一集，也允许一场拆成多集，按搞笑密度和故事收尾决定。
  前期追进度时偏浓缩；追上进度后可放慢。二十多分钟是本次系列的参考目标，不能靠无趣段落补足。
- 从怪话、嘴硬与打脸、误解、操作翻车、惊吓和反应中找节拍。按每个笑点的
  “前提—动作/发言—结果—反应”选片，不把关键词命中当完整笑点。
- 保留必要的目标选择，例如“我们去哪？去某地吧”，让观众知道下一段为何换地方。
  重复尝试中保留首次、升级、反转与最终结果，删掉没有新信息的重复跑图和教程。
- 捏脸、学习洞窟和长时间打 Boss 都按有效节拍压缩；首集第一晚被压到几分钟是具体编辑结果，
  不能推广成所有直播固定保留比例。战斗胜负、掉落和死亡原因必须看游戏画面，不能只读字幕推断。
- 正文保持实际游玩顺序。可以在开头用十几至几十秒的本集预告，再接短 OP/“快乐小岁#NN”
  标题分隔。预告也需要完整笑点和舒服的话尾，不为了快而截半个词。
- 跨场或省略长时间尝试时用简短上方说明或转场卡。用可证实的录播时间差写“X小时后”；
  跨晚用“第二晚/第三晚”，不能把几场间隔冒称连续打了同样长时间。
  原游戏混音优先；额外 BGM、笑声或音效按内容需要决定，并记录来源。

## 台词和音画边界

ASR 的字幕结束时间只是锚点，不能直接当最后一个音节的结束。按
[音频边界与交付证据](references/boundaries-and-delivery.md) 检查真实语音、音量包络、
笑声/叫声与后续词；有疑问先扩大局部上下文，不重跑整场 ASR。

不要把语义删减变成逐字硬切。先确定完整句组，再给声音留前后余量。
字幕显示结束、语音结束、动作完成可以是三个不同时间。
字幕按保留的源区间重新映射，不能只改 SRT 而保留旧烧录视频。

长字幕沿用项目标准大字号，按实际画面换行；居中 ASS 的左右边距应相同。
本集用过左右各 32、每行约 10 字，但这些是当前画幅的验证值，不是所有分辨率的通用值。
抽查成片中最短句、长句、跨转场句和靠边主体；不能把右偏问题归因于预览压制而不查实片。

## 封面与文案

封面可用岁己参考形象加本集可辨认的游戏元素，参考项目“晚安回复”插画的色彩与质感。
读取 imagegen skill 后生成/编辑，并查看原图与小尺寸效果。角色衣帽原有标记可保留。
主文案少字：`快乐小岁#NN` 加具体主题，例如“初见法环”“初见大树守卫”；
泛泛的怪话不能代替本集到底发生了什么。标题、封面、简介和章节均从实际保留内容取证。
封面为 AI 插画时写明来源，不冒称游戏原截图。独立检查角色身份、游戏主体、文字和构图。

## 审看、投稿与归档

输出独立修订版，保留用户已看过的旧版。保存源绝对时间、成片时间、字幕映射、
转场依据、来源身份、真实检查结果和下一集起点。任务脚本与研究证据放忽略的 `temp/`，
最终视频和 sidecar 放录播旁 `manual_requested_clips`，不要把整套大媒体提交到 Git。

先做完整解码、所有保留区间的原音对齐、字幕越界检查和关键画面对照，再核对完整保留文本的
连续性以及全部公共文案。波形/VAD/ASR 和视觉检查不等于人耳完整听审；如实记录覆盖范围。
视频有修改就重跑相应检查并重新绑定视频、字幕、封面、文案摘要，旧 QA 不能原样沿用。

用户当前任务的投稿授权允许完成该集的修订与发布，不能自动扩大成后续每集都可发布。
已授权时沿用现有上传注册表与单 worker；`import-json`/`enqueue` 的实际命令见
`docs/topic-event-editorial.md` 与 bilibili-clip-upload skill。既有数字 ID 继续使用原 ID，
不要创建第二条候选绕过失败。单源候选改词使用 `correct`；多源合集不能伪装成单源重剪。

合集“快乐小岁系列”要查询并复用。合集的 season ID 与 section ID 不同，入队使用实际
section ID；不存在时在用户授权内创建一次。系列标题自带前缀时，元数据 `upload.prefix: ""`
表示明确不加前缀；不要擅自补上“【小岁】”，否则会与已审文案不一致。

入队回执只证明入队；传输 100% 也不证明投稿成功。有提交回执/BV 才报告已投稿。
失败先查 worker 原因和提交意图：提交前失败可按原 ID 修复重试；POST 结果不明须先走
既有 reconciliation，已发布则编辑原 BV，不能重复新投。入队后确认 worker 在线即可，
不要靠持续轮询等待；用户再问进度时读取当前真实状态。
