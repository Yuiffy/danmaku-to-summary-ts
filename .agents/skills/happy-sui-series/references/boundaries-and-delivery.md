# 原音边界与交付证据

## 局部分析

为每个保留区间保存源起止、最后/最先保留的词、前后词，以及数秒的上下文。
先用真实原音做语音活动检测（VAD），同时计算约 10 ms 的 RMS 音量包络。
本地已有 FSMN 模型时可以复用缓存并限定 CPU 线程；不要为每个边界另启大模型或下载模型。
音量大可能只是游戏/BGM，音量小可能仍是轻声词尾；任意一个阈值都不能证明台词完整。

优先在最后保留词之后的语音落点外留短余量，常见约 0.12–0.25 秒，按实际发声调整。
向前留少量预滚避免吞首音；必须防止带入上一句末尾。检测窗口的最右边是分析截断，
不是已发现停顿。连续说话超出搜索窗应扩大局部上下文或保留完整后一句，不能无限自动延长。
笑声、气音、尖叫与动作结果可能未被 ASR/VAD 识别，应单独保留和核查。

检查新增字幕字词：只多出“这不是”“话说”“我觉得”等半句时，找到上一完整落点，
或把后面整句接完；不能把这些字简单隐藏，音频却仍留下半句。
新增英文/NPC 语音可能被中文 ASR 误写，应核对声音和游戏语境，不能把乱码直接烧入。
相邻源区间若本来连续且中间无转场，优先合并成一个连续渲染段，避免重复编码造成接缝。

## 纯规则辅助函数

`src/scripts/python/speech_cut_boundary.py` 的 `refine_boundary` 只做决策，不读取媒体、
不加载模型、不调用注册表。输入全部使用录播绝对秒数：

- `original`、`side`（start/end）、`anchor`（首词起点/末词终点）；
- `speech` 为局部 VAD `[start,end]` 列表；
- `envelope_start`、`rms_db` 与 `frame_seconds` 描述原混音的等间隔 dBFS 包络；
- `lower`/`upper` 为相邻保留段或经复核的词边界保护，`max_shift` 限制移动范围。

返回 `cut/status/method/speech_edge`。`passed` 只表示这一份输入满足保守声学规则，
不代表下一句语义、字幕、动作或整片已获批准。`needs_review` 保持原点，必须实际解决，
不能把“保持原点”自动当作质量通过。已有余量足够时可以不改切点。
RMS 回退只接受 VAD 未占用的低能量停顿；VAD 连续但实际是 NPC/游戏声时需单独取证判断。

该函数尚未接入自动切片或注册表重建。系列任务可通过自己的局部适配器传入证据，
记录逐段决定再交给原渲染接口；不能声称提交该文件就已修复所有未来自动切片。
行为回归：`python -m unittest tests.test_speech_cut_boundary -q`。

## 时间轴和成片复核

每一段保存 `sourceId/start/end/finalStart/duration` 及源文件身份。
局部转写的零点、粗剪文件的零点与原录播零点分别保存，不能重复减偏移量。
渲染复用 `topic_clipper.cutClipMedia` 与 `topic_compilation.buildDefaultCompilationMediaConfig`，
通过 `resource_scheduler` 获取配置的 NVENC/CUDA 资源；不要把本机路径、线程数和编码器
写成固定的共享命令。复用缓存须绑定源身份、边界、字幕和媒体参数。

合并时音视频取同一源窗口，统一实际帧率和音频采样率，用帧/采样整数计算累计时长。
独立版本可复用未变片段；不能硬链接旧文件后原地覆写。短淡出只能处理已完整说完的尾巴，
不能用淡出掩盖被截断的词。

验收覆盖每个源区间的开始、中间、末尾原音相关性/偏移，完整解码，字幕时间范围，
源文件身份和实际分辨率/帧率。原音对齐只能证明取到了正确位置，不能证明语义收尾正确；
另查新增台词完整性和自然停顿。章节和简介从最终时间轴重算，不能复用旧时刻。
制作清单写出下一集可继续的录播起点、已用源区间和未解决的听审限制。
